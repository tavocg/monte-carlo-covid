\begin{frame}{Pregunta de investigación}
  \begin{block}{Pregunta}
    ¿Cómo puede un modelo de simulación Monte Carlo, aplicado por zona
    geográfica y basado en Xie \cite{Xie2020}, estimar la cantidad esperada de
    casos nuevos de COVID-19 a partir de series temporales observadas?
  \end{block}

  \begin{itemize}
    \item Se trabaja con datos nacionales del Oxford COVID-19 Government
          Response Tracker \cite{Hale2021}.
    \item La simulación resume la incertidumbre mediante promedios y
          percentiles.
  \end{itemize}
\end{frame}

\begin{frame}{Objetivo}
  \begin{block}{Objetivo general}
    Desarrollar un modelo de simulación Monte Carlo para estimar casos nuevos
    de COVID-19 en distintas zonas geográficas.
  \end{block}

  \begin{itemize}
    \item Adaptar el procedimiento de Xie \cite{Xie2020}.
    \item Construir series diarias por país.
    \item Estimar \(R_t\) desde casos observados.
    \item Comparar trayectorias simuladas con casos reales.
  \end{itemize}
\end{frame}

\begin{frame}{Datos utilizados}
  \begin{itemize}
    \item Países: Australia, Brasil, Canadá, China, Reino Unido, India y
          Estados Unidos.
    \item Columnas usadas: \texttt{CountryName}, \texttt{CountryCode},
          \texttt{Jurisdiction}, \texttt{Date} y \texttt{ConfirmedCases}.
    \item Se conservan solo observaciones nacionales:
          \texttt{Jurisdiction = NAT\_TOTAL}.
    \item Los casos nuevos se calculan como diferencias diarias no negativas
          sobre casos acumulados.
  \end{itemize}
\end{frame}

\begin{frame}[fragile]{Preparación de datos: columnas y filtro}
  \small
  El procesamiento carga únicamente las columnas usadas por el modelo y elimina
  observaciones subnacionales.

  \vspace{0.3cm}

  \scriptsize
  \begin{verbatim}
cols = ["CountryName", "CountryCode", "Jurisdiction",
        "Date", "ConfirmedCases"]
df = pd.read_csv(path, usecols=cols)

df = df[df["Jurisdiction"].eq("NAT_TOTAL")].copy()
  \end{verbatim}

  \normalsize
  \begin{itemize}
    \item \texttt{NAT\_TOTAL} conserva el total nacional de cada país.
    \item Esto evita mezclar regiones internas con series nacionales.
  \end{itemize}
\end{frame}

\begin{frame}[fragile]{Preparación de datos: casos nuevos}
  \small
  El dataset reporta \texttt{ConfirmedCases} como acumulado. Por eso los casos
  nuevos diarios se calculan con diferencias entre días consecutivos.

  \vspace{0.3cm}

  \scriptsize
  \begin{verbatim}
df["confirmed_cases"] = pd.to_numeric(
    df["ConfirmedCases"], errors="coerce"
)

df["observed_new_cases"] = (
    df["confirmed_cases"]
    .diff()
    .fillna(df["confirmed_cases"])
    .clip(lower=0)
    .round()
)
  \end{verbatim}
\end{frame}

\begin{frame}{Estimación de \(R_t\)}
  \begin{itemize}
    \item Los datos no incluyen \(R_t\) directamente.
    \item Se aproxima con el cociente entre:
      \[
        \frac{\text{promedio móvil de 7 días}}{\text{promedio móvil desplazado 5 días}}
      \]
    \item El valor se limita al intervalo \([0,2]\) para reducir inestabilidad
          numérica.
    \item La serie inicia cuando hay al menos 100 casos nuevos diarios.
  \end{itemize}
\end{frame}

\begin{frame}[fragile]{Estimación de \(R_t\): código}
  \small
  El promedio móvil suaviza reportes irregulares. El \texttt{shift(5)}
  compara el nivel reciente de casos con el nivel de cinco días antes.

  \vspace{0.2cm}

  \scriptsize
  \begin{verbatim}
smoothed = (
    df["observed_new_cases"]
    .rolling(rt_window, min_periods=1, center=False)
    .mean()
)
previous = smoothed.shift(rt_lag)
rt = (smoothed / previous).replace([np.inf, -np.inf], np.nan)
df["Rt"] = rt.fillna(1.0).clip(lower=rt_min, upper=rt_max)
  \end{verbatim}

  \normalsize
  En la configuración usada: \texttt{rt\_window = 7},
  \texttt{rt\_lag = 5}, \texttt{rt\_min = 0} y \texttt{rt\_max = 2}.
\end{frame}

\begin{frame}[fragile]{Inicio de la serie simulada}
  \small
  La simulación no empieza desde el primer registro del archivo. Se recorta la
  serie hasta que exista una señal mínima de transmisión.

  \vspace{0.3cm}

  \scriptsize
  \begin{verbatim}
first_case = df.index[
    df["observed_new_cases"].ge(min_daily_cases)
]
if len(first_case) == 0:
    first_case = df.index[df["observed_new_cases"].gt(0)]
if len(first_case) == 0:
    return df.iloc[0:0].copy()
return df.loc[first_case[0] :].reset_index(drop=True)
  \end{verbatim}

  \normalsize
  En la configuración usada, \texttt{min\_daily\_cases = 100}.
\end{frame}

\begin{frame}{Modelo estocástico}
  Para un día \(t\), si hay \(I_t\) casos nuevos simulados:

  \[
    S_t \sim \operatorname{Poisson}(I_t R_t)
  \]

  \begin{itemize}
    \item \(S_t\): contagios secundarios generados desde el día \(t\).
    \item Los retrasos se asignan con una binomial negativa.
    \item El proceso se repite muchas veces para aproximar el valor esperado:
      \[
        E[K_{z,t}] \approx \frac{1}{N}\sum_{k=1}^{N}K_{z,t}^{(k)}.
      \]
  \end{itemize}
\end{frame}

\begin{frame}[fragile]{Retrasos con binomial negativa}
  \small
  La distribución de retrasos asigna en qué día futuro aparecen los contagios
  secundarios. La posición cero representa un retraso de un día.

  \vspace{0.2cm}

  \scriptsize
  \begin{verbatim}
p = dispersion / (dispersion + mean_delay)
probs = np.empty(max_delay, dtype=float)
probs[0] = p**dispersion

for idx in range(1, max_delay):
    failures = idx - 1
    probs[idx] = (
        probs[idx - 1] * (failures + dispersion)
        / idx * (1 - p)
    )
  \end{verbatim}

  \normalsize
  En la simulación base se usa media 5 y dispersión 2.
\end{frame}

\begin{frame}[fragile]{Asignación de contagios secundarios}
  \small
  Una vez generado el total de casos secundarios, se distribuyen en días
  futuros según las probabilidades de retraso.

  \vspace{0.2cm}

  \scriptsize
  \begin{verbatim}
total_secondary_cases = rng.poisson(
    lam=infected_today * rt_values[day]
)

delay_counts = rng.multinomial(
    n=int(valid_secondary_cases),
    pvals=valid_probs / valid_probs_sum,
)
simulated_new_cases[day + 1 : day + 1 + remaining_days] += delay_counts
  \end{verbatim}
\end{frame}

\begin{frame}{Flujo computacional}
  \begin{enumerate}
    \item Preparar series por país.
    \item Estimar casos nuevos diarios y \(R_t\).
    \item Ejecutar 1000 simulaciones por país.
    \item Resumir promedios y percentiles diarios.
    \item Generar figuras comparando simulación y observación.
  \end{enumerate}
\end{frame}

\begin{frame}{Interpretación}
  \begin{itemize}
    \item El modelo reproduce cualitativamente algunos periodos de crecimiento.
    \item No es una reconstrucción exacta de los casos reales.
    \item La simulación se alimenta de su propia trayectoria después del primer
          día.
    \item Brotes importados, cambios de reporte y heterogeneidad regional no se
          modelan explícitamente.
  \end{itemize}
\end{frame}

\begin{frame}{Conclusiones}
  \begin{itemize}
    \item El enfoque Monte Carlo permite estimar trayectorias esperadas y
          rangos de incertidumbre.
    \item La disponibilidad de variables condiciona la forma final del modelo.
    \item El método no debe compararse directamente con modelos SIR, SEIR o
          bayesianos: tiene un alcance más exploratorio y operativo.
    \item La simulación depende de su propia trayectoria después del día
          inicial, por lo que errores tempranos pueden amplificarse.
  \end{itemize}
\end{frame}

\begin{frame}{Sugerencias}
  \begin{itemize}
    \item Una versión predictiva debería incorporar reinyección de casos
          observados y calibración por ventanas.
    \item Sería útil ajustar parámetros por país o por subregión para capturar
          heterogeneidad espacial.
    \item Una extensión futura podría tratar las medidas sanitarias como
          variables aleatorias o covariables.
    \item Con múltiples simulaciones, se podrían estimar pesos asociados a esas
          medidas y explorar cuáles se relacionan con menor transmisión.
    \item Ese análisis queda fuera del alcance actual y requeriría controles
          adicionales para no confundir correlación con causalidad.
  \end{itemize}
\end{frame}
